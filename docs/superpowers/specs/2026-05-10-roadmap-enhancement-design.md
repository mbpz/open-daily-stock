## 一、研究概述

通过对 4 个维度的竞品分析，识别出 open-daily-stock 的竞争优势、差距和改进方向。

### 1.1 竞品全景

| 项目 | 类型 | 目标用户 | 核心特点 |
|------|------|---------|---------|
| **TradingView** | 云端 + 桌面 | 全球零售/专业 | 100+指标，强大图表，社区，Pine Script |
| **雪球 (Xueqiu)** | 云端 | 中国零售 | 社交炒股，AI分析，兴趣推荐 |
| **同花顺** | 桌面/移动 | 中国零售 | L2行情，AI问财，dense专业界面 |
| **富途牛牛** | 桌面/移动 | 港美股投资者 | 现代UI，暗色主题，智能 alerts |
| **Wind** | 终端 | 机构 | L2，昂贵，专业，键盘驱动 |
| **Backtrader** | Python库 | 量化开发者 | 回测框架，无UI，纯代码 |
| **Zipline** | 云端 | Quant researchers | 管道架构，美股为主 |
| **VNPY** | 桌面 | 中国量化 | CTA策略，插件架构，CTP网关 |
| **AkShare/YFinance** | Python库 | 数据分析师 | 数据源，无存储/无UI |

### 1.2 open-daily-stock 差异化定位

```
竞品定位象限图:

        专业/昂贵
           │
    Wind  │  雪球/同花顺
  (机构)  │  (中国零售)
           │
───────────┼───────────────
           │           零售/免费
  Backtrader │  open-daily-stock ← 你在这里
  (代码驱动)  │  (本地+AI+TUI/GUI)
           │
    Zipline │  TradingView
           │
        简单/功能少
```

**open-daily-stock 独占的差异化:**
1. **本地优先 + 开源** — 无服务器，数据私有，隐私敏感人群
2. **TUI+GUI 双模式** — 无任何竞品同时提供终端+图形界面
3. **LLM 决策仪表盘** — 非简单指标，是真正的 AI 分析对话
4. **多渠道中文通知** — 企业微信/飞书/Telegram组合独特
5. **A+HK+US 一体化** — 覆盖三个市场且开源免费

## 二、技术架构分析与改进

*来源: Architecture Agent*

### 2.1 当前架构评估

open-daily-stock 架构**适合其定位**（本地优先个人工具），但存在以下问题：

| 问题 | 影响 | 优先级 |
|------|------|--------|
| **双存储混用** — storage.py 用 SQLAlchemy，data_service.py 用 raw sqlite3 | schema 不一致，维护困难 | P1 |
| **stdio JSON 单向阻塞** — 无法双向推送，readline 阻塞 | 复杂交互受限 | P1 |
| **无 per-request 超时** — handler 挂死导致整个 daemon 卡住 | 可用性问题 | P2 |
| **无 request tracing** — 日志无请求关联 | 生产调试困难 | P2 |

### 2.2 架构改进建议

#### 改进 1: 统一存储层 (P1)
```
现状: data_service.py 用 raw sqlite3 → storage.py 用 SQLAlchemy ORM
建议: 全部迁移到 storage.py 的 SQLAlchemy ORM
      positions/markets/task 表统一管理
收益: 消除 schema 重复定义，统一事务语义
```

#### 改进 2: 添加 WebSocket IPC 模式 (P1)
```
现状: stdio JSON，只能单向推送
建议: 添加 --websocket 模式，DataService 启动 WebSocket server
      TUI/GUI 可选择 stdio 或 WebSocket 连接
收益: 支持真正的双向异步通信
```

#### 改进 3: per-request 超时保护 (P2)
```
现状: 网络 I/O 挂死 → daemon 整体卡住
建议: 每个 action handler 用 thread pool + timeout
      挂死超过 30s → 自动 cancel + 返回超时错误
收益: 单个请求不拖累整个服务
```

#### 改进 4: ADR 文档 (P2)
```
建议: 创建 docs/adr/ 目录，记录关键决策
  - ADR-001: SQLite 作为主存储
  - ADR-002: stdio JSON IPC 机制
  - ADR-003: Gemini + OpenAI fallback AI 策略
  - ADR-004: DataFetcherManager 策略模式
收益: 贡献者 onboarding，降低未来重构风险
```

### 3.3 功能改进建议

#### 建议 1: 扩展技术指标 (P1)
```
现状: 只有 MA5/10/20
建议: 增加 RSI, MACD, Bollinger Bands, KDJ, WR, OBV
实现: mplfinance 支持 custom indicators
      在 charts.py 中增加 indicator registry
收益: 技术分析实用性大幅提升，工作量低
```

#### 建议 2: 股票选股器 (P1)
```
现状: 只能跟踪预配置自选股
建议: AkShare 提供选股数据 (市值, PE, 行业, 涨跌幅筛选)
      在 Config 页面增加选股器表单
      选股结果可一键加入自选股
收益: 用户发现新机会，核心功能差距
```

#### 建议 3: 画线工具 (P1)
```
现状: K线图无画线工具
建议: 使用 matplotlib annotations 支持:
      - 趋势线 (trend lines)
      - 支撑/压力位
      - 斐波那契回调
收益: 将图表从显示工具升级为分析工具
```

#### 建议 4: 模拟交易 (P1)
```
现状: 无模拟交易
建议: 利用已有的 backtester + portfolio 模块
      新增 "模拟账户" 模式:
      - 虚拟资金 (默认 100万)
      - 记录模拟买卖
      - 计算模拟持仓盈亏
收益: 用户无风险测试策略
```

#### 建议 5: 专属 Alert UI (P1)
```
现状: 告警需要编辑 config.json
建议: 在 Config 页面增加 Alerts tab:
      - 股票 + 条件 (价格 above/below X) + 渠道
      - 列表展示所有告警，可开关
      - Markets 页显示有告警的股票标记
收益: 用户留存率提升
```

#### 建议 6: 财务报表数据 (P2)
```
现状: 无财务报表
建议: 使用 AkShare 的财务报表接口
      在 K线页面增加 "财务" tab
收益: 填补基本面分析空白
```

*来源: Market Strategy Agent + 领域知识*

### 5.1 市场定位

```
价格 →
免费                    昂贵
  │  AkShare                    Wind
  │  YFinance               FactSet
  │  open-daily-stock ←---
  │  TradingView (free)
  │  雪球 (免费)
  │
  └────────────────────────────────→
                    功能复杂度 →
```

**当前定位:**
- 价格: 免费开源
- 功能: 中等复杂 (AI分析 + 持仓 + K线 + 机构追踪 + 回测)
- 用户: 技术型个人投资者，中文用户为主
- 市场: 本地优先，隐私敏感

**空白区域 (open-daily-stock 占据):**
> 免费 + 本地优先 + AI分析 + A股覆盖 + TUI/GUI双模式

这个组合在竞品中**完全空白**。

### 5.2 竞争优势 (Moats)

| 护城河 | 强度 | 说明 |
|--------|------|------|
| **开源本地优先** | 强 | 数据不出本机，隐私敏感用户强烈偏好 |
| **TUI+GUI 双模式** | 强 | 无竞品同时提供，技术+非技术用户全覆盖 |
| **多渠道中文通知** | 中 | 企业微信+飞书+Telegram组合独特 |
| **AkShare 集成** | 中 | A股免费数据+本地=无服务器成本 |
| **LLM 决策仪表盘** | 中 | 真正 AI 分析，非简单指标罗列 |

### 5.3 市场机会

1. **隐私敏感人群** — 中国用户对数据隐私意识增强，本地优先是核心卖点
2. **技术用户社区** — AkShare/YFinance 用户群与 open-daily-stock 高度重叠
3. **量化交易者** — Backtrader/Zipline 用户需要本地回测+实时监控
4. **中文通知需求** — 飞书/企业微信机器人在中国用户中广泛使用
