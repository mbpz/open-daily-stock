## 一、研究概述

通过对 9 个竞品的 4 维度分析，识别出 open-daily-stock 的竞争优势、差距和改进方向。

### 1.1 竞品全景

| 项目 | 类型 | 目标用户 | 核心特点 |
|------|------|---------|---------|
| **TradingView** | 云端 + 桌面 | 全球零售/专业 | 100+指标，强大图表，社区，Pine Script |
| **雪球 (Xueqiu)** | 云端 | 中国零售 | 社交炒股，AI分析，兴趣推荐 |
| **同花顺** | 桌面/移动 | 中国零售 | L2行情，AI问财，dense专业界面 |
| **富途牛牛** | 桌面/移动 | 港美股投资者 | 现代UI，暗色主题，智能 alerts |
| **Wind** | 终端 | 机构 | L2，昂贵，专业，键盘驱动 |
| **Backtrader** | Python库 | 量化开发者 | 回测框架，无UI，纯代码 |
| **Zipline** | 云端 | Quant researchers | 管道架构，美股为主 |
| **VNPY** | 桌面 | 中国量化 | CTA策略，插件架构，CTP网关 |
| **AkShare/YFinance** | Python库 | 数据分析师 | 数据源，无存储/无UI |

### 1.2 open-daily-stock 差异化定位

```
竞品定位象限图:

        专业/昂贵
           │
    Wind  │  雪球/同花顺
  (机构)  │  (中国零售)
           │
───────────┼───────────────
           │           零售/免费
  Backtrader │  open-daily-stock
  (代码驱动)  │  (本地+AI+TUI/GUI)
           │
    Zipline │  TradingView
           │
        简单/功能少
```

**open-daily-stock 独占的差异化:**
1. **本地优先 + 开源** — 无服务器，数据私有，隐私敏感人群
2. **TUI+GUI 双模式** — 无任何竞品同时提供终端+图形界面
3. **LLM 决策仪表盘** — 非简单指标，是真正的 AI 分析对话
4. **多渠道中文通知** — 企业微信/飞书/Telegram组合独特
5. **A+HK+US 一体化** — 覆盖三个市场且开源免费

## 二、技术架构分析

### 2.1 架构对比

| 维度 | open-daily-stock | TradingView | 雪球/同花顺 | 富途 |
|------|-----------------|-------------|-------------|------|
| 部署模式 | 本地优先 | 云端 | 云端 | 桌面/云端 |
| 数据存储 | SQLite本地 | 服务器 | 服务器 | 服务器 |
| 通信机制 | stdio JSON | WebSocket | WebSocket | WebSocket |
| 图表引擎 | mplfinance | 自研D3 | 自研 | 自研 |
| AI 集成 | Gemini/OpenAI | 无 | 基础 | 无 |
| 开源 | ✅ | ❌ | ❌ | ❌ |

### 2.2 当前架构问题

| 问题 | 影响 | 优先级 |
|------|------|--------|
| **双存储混用** — storage.py 用 SQLAlchemy，data_service.py 用 raw sqlite3 | schema 不一致，维护困难 | P1 |
| **stdio JSON 单向阻塞** — 无法双向推送，readline 阻塞 | 复杂交互受限 | P1 |
| **无 per-request 超时** — handler 挂死导致整个 daemon 卡住 | 可用性问题 | P2 |
| **无 request tracing** — 日志无请求关联 | 生产调试困难 | P2 |

### 2.3 架构改进建议

| 改进 | 描述 | 收益 |
|------|------|------|
| P3-8: 统一存储层 | 全部迁移到 storage.py SQLAlchemy ORM | 消除 schema 重复，统一事务语义 |
| P3-9: WebSocket IPC | DataService 支持 WebSocket server | 双向异步通信 |
| P3-10: per-request 超时 | handler thread pool + 30s timeout | 单请求不拖累服务 |

## 五、市场策略分析

### 5.1 市场定位

```
价格 →
免费                    昂贵
  │  AkShare                    Wind
  │  YFinance               FactSet
  │  open-daily-stock ←---
  │  TradingView (free)
  │  雪球 (免费)
  │
  └────────────────────────────────→
                    功能复杂度 →
```

**空白区域 (open-daily-stock 占据):**
> 免费 + 本地优先 + AI分析 + A股覆盖 + TUI/GUI双模式

### 5.2 竞争优势

| 护城河 | 强度 | 说明 |
|--------|------|------|
| **开源本地优先** | 强 | 数据不出本机，隐私敏感用户 |
| **TUI+GUI 双模式** | 强 | 无竞品同时提供 |
| **多渠道中文通知** | 中 | 企业微信+飞书+Telegram组合 |
| **AkShare 集成** | 中 | A股免费数据+本地 |
| **LLM 决策仪表盘** | 中 | 真正 AI 分析 |

### 5.3 市场机会

1. **隐私敏感人群** — 中国用户数据隐私意识增强
2. **技术用户社区** — AkShare/YFinance 用户群高度重叠
3. **量化交易者** — Backtrader/Zipline 用户需要本地回测
4. **中文通知需求** — 飞书/企业微信机器人广泛使用

### 5.4 战略建议

| 战略 | 行动 | 收益 |
|------|------|------|
| 强调隐私定位 | README 强调"你的数据只存在你的电脑里" | 差异化清晰 |
| AkShare 用户营销 | AkShare 社区推广 | 精准触达 |
| 完善文档 | 场景化 README + 对比表 + 截图 | 转化率提升 |

## 七、总结

### 核心优势
1. **本地优先** — 唯一开源+本地+无服务器
2. **TUI+GUI 双模式** — 独占，无竞品对标
3. **LLM 决策仪表盘** — 真正 AI 分析
4. **多渠道中文通知** — 企业微信+飞书+Telegram
5. **A+HK+US 一体化** — 三个市场覆盖

### 最需要补齐的短板
1. **技术指标** (RSI/MACD等)
2. **Alert 配置 UI**
3. **股票选股器**
4. **画线工具**

### 战略定位
> **"个人股票分析工作站"** — 本地优先，AI驱动，TUI/GUI双入口
> 对比雪球/同花顺的云端模式，强调隐私和数据主权
